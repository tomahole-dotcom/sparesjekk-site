# Sparesjekk.no

Sparesjekk.no er en norsk informasjonsside om privatøkonomi med guider og gratis verktøy for blant annet boliglån, refinansiering, forbrukslån og kredittkort.

**Nettside:** https://sparesjekk.no/

## Nyttige verktøy og guider

- [Sjekk boliglånsrenten mot markedet](https://sparesjekk.no/min-rente-vs-markedet.html)
- [Rentegap-indeks – styringsrente mot faktisk boliglånsrente](https://sparesjekk.no/rentegap-indeks.html)
- [Beregn hva en renteforskjell betyr i kroner](https://sparesjekk.no/boliglanskalkulator-renteforskjell.html)
- [Refinansiering-kalkulator](https://sparesjekk.no/refinansiering-kalkulator.html)
- [Belåningsgrad-sjekk](https://sparesjekk.no/belaningsgrad-sjekk.html)

## Om prosjektet

Innholdet er laget for å gjøre økonomiske begreper og valg lettere å forstå. Sparesjekk.no er ikke en bank og innholdet er generell informasjon, ikke personlig økonomisk rådgivning.

Dette repositoriet brukes til utvikling og kvalitetssikring av nettstedet.
