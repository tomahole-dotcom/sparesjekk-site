# Sparesjekk Design Profile Lock

Status: LOCKED
Effective: 2026-09-19

## Source of truth
The unified BLUE brand system introduced in design-v36.css and refined by later design files is the only approved visual profile for Sparesjekk.no.

## Mandatory rules
- New pages, tools, calculators, decision cards and commercial journeys must use the existing blue V36+ design language.
- Primary actions use the blue brand treatment based on --brand / --brand-dark.
- Do not create a separate green CTA/profile.
- Reuse existing typography, spacing, border radius, shadows, cards, inputs and responsive behavior before adding new component styling.
- Desktop and mobile must remain visually consistent with the same profile.
- New UI work must receive design QA together with functional/SEO QA before being called complete.
- Existing SEO copy, metadata and commercial routing must not be changed merely for visual alignment.

## Legacy variable warning
design-v36.css intentionally maps legacy --green and --green-dark variables to blue values for backwards compatibility. Variable names do not define the current brand color. The rendered V36+ blue system is authoritative.

## Release rule
A new or modified user-facing component is not design-approved until it inherits or explicitly matches the blue V36+ profile and passes responsive QA.
