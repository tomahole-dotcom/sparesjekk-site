Relevant problem -> hjelpsomt svar -> eventuell deep-link bare dersom reglene tillater det og verktøyet faktisk løser spørsmålet.

- «Er boliglånsrenten min god?» -> min-rente-vs-markedet.html
- «Hvor mye betyr 0,25 prosentpoeng?» -> boliglanskalkulator-renteforskjell.html
- «Bør jeg bytte bank?» -> bankbytte-break-even.html
